## Plan: Dimension KPI Cards + Multi-Quarter Trend Charts

### Context
- The source table `REPORTING.GTM_ANALYTICS.EXEC_DECK_RENEWAL_RATES_PRODUCT_GROUP` has `DATE_YQ`, `REGION`, and `PRODUCT_GROUP_CLEANED` columns across all quarters.
- The existing `02_scorecard_dimensions.sql` only returns the current quarter. For KPI cards with QoQ/YoY comparisons and 5-quarter trend charts, I need a new query that returns multi-quarter data by dimension.
- Product solution mapping: EO (7 product groups), EC (6 product groups), AI/Opal (1 product group).
- Required dimensions: Product Solution = {EO, EC, Opal}, Region = {NA, EMEA, APJ}.

### Implementation Steps

**1. Create new SQL `queries/02b_dimensions_trend.sql`**
- Query `EXEC_DECK_RENEWAL_RATES_PRODUCT_GROUP` for the 5 most recent quarters up to `:target_quarter`
- Deduplicate same as existing query (ROW_NUMBER per MASTER_CUSTOMER_ID, PRODUCT_GROUP_CLEANED, DATE_YM)
- Return two UNION ALL sections:
  - By Region (DATE_YQ, 'Region' as dimension_type, REGION as dimension_value, renewal_arr, churn_arr, renewal_rate)
  - By Product Solution (DATE_YQ, 'Product Solution' as dimension_type, product_solution as dimension_value, renewal_arr, churn_arr, renewal_rate)
- Filter to only the dimension values we care about: regions IN ('NA','EMEA','APJ'), product solutions IN ('EO','EC','AI')

**2. Update `query_tools.py` — `scorecard_dimensions()` function**
- Add a second query call to `02b_dimensions_trend.sql`
- Return `{"main": current_quarter_df, "trend": multi_quarter_df}`

**3. Rewrite `_section_scorecard_dimensions()` in `render_html.py`**
- Remove the tabbed table approach entirely
- Build the section with:

  **Part A — Product Solution KPIs** (heading + 3 KPI cards for EO, EC, Opal):
  - Each card shows: Renewal ARR (large), Churn ARR, Renewal Rate
  - Below each value: vs prior quarter + % change, vs YoY + % change
  - Derive prior/yoy from the trend DataFrame (filter by dimension_value and DATE_YQ)

  **Part B — Region KPIs** (heading + 3 KPI cards for NA, EMEA, APJ):
  - Same format as product solution KPIs

  **Part C — Renewal Rate Trend** (2 line charts side by side):
  - Left: Renewal Rate by Product Solution (3 lines: EO, EC, Opal) + avg dashed
  - Right: Renewal Rate by Region (3 lines: NA, EMEA, APJ) + avg dashed

  **Part D — ARR & Churn Charts** (6 bar charts in 2x3 grid or stacked):
  - One bar chart per region (Renewal ARR + Churn ARR negative, 5 quarters)
  - One bar chart per product solution (Renewal ARR + Churn ARR negative, 5 quarters)

**4. Helper functions**
- Add `_prior_quarter(q)` and `_yoy_quarter(q)` helpers to derive comparison quarter labels
- Reuse `_chartjs_bar()` and `_chartjs_line()` for all charts
