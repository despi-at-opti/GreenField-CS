## Context

**Base query** (`01_sfdc_base.sql`): SFDC churn data, rolling 8 quarters, line-item weighted. Output columns include `CSM` (TAM_CSM), `ACCOUNT_ID`, `DATE_YQ`, `REGION`, `SEGMENT`, `DO_FIT`, `CSM_TEAM`, `SOLUTION_TYPE`, `PRODUCT_SOLUTION`, `PRODUCT_GROUP`, `LINE_OF_BUSINESS`, `CHURN_LABEL`, `PRIMARY_CHURN_TYPE`, `CHURN_CATEGORY`, `FULL_CHURN_ARR`, `DOWNGRADE_ARR`, `ARR_RENEWAL`, `EMPLOYEE_NAME`, etc.

**ARR bands** (`00_account_arr_bands.sql`): Separate SST-sourced query with `ACCOUNT_ID`, `SNAPSHOT_MONTH`, `ARR_BAND`. Needs to be loaded separately and joined by `ACCOUNT_ID` + quarter-aligned snapshot.

**Pattern**: Follows `04_sfdc_analysis.py` — direct `snowflake.connector.connect(connection_name="OPTIMIZELY_DATA_SERVICES")`, manual SQL param replacement, pandas analysis, Excel export.

## Implementation — `pandas/01_csm_sfdc_analysis.py`

### Structure

1. **Config**: `TARGET_QUARTER`, paths to `01_sfdc_base.sql` and `00_account_arr_bands.sql`, output dir, list of 11 dimensions
2. **`load_data()`**: Load base SQL, replace `:target_quarter`, compute `TOTAL_CHURN_ARR`
3. **`load_arr_bands()`**: Load ARR bands query, return full dataset
4. **`merge_arr_bands(df, bands)`**: For each quarter in `df`, find the latest snapshot per `ACCOUNT_ID` from the prior quarter end, merge `ARR_BAND` onto `df`
5. **`_agg_metrics(df, group_cols)`**: Shared aggregation helper — groups by `group_cols`, computes: `ACCOUNTS` (nunique), `ARR_BASELINE` (sum), `FULL_CHURN_ARR` (abs sum), `DOWNGRADE_ARR` (abs sum), `TOTAL_CHURN_ARR`, `RENEWAL_RATE` (%)

### Analysis functions (all keyed by CSM)

| Function | Grouping | Scope | Excel Sheet(s) |
|---|---|---|---|
| `csm_totals(df)` | CSM | Target Q | "CSM Totals" |
| `csm_quarterly_trend(df)` | CSM × DATE_YQ | All Qs | "CSM Quarterly Trend" |
| `csm_by_dimension(df, dim)` | CSM × dimension | Target Q | "Q_{dim}" (×11) |
| `csm_trend_by_dimension(df, dim)` | CSM × DATE_YQ × dimension | All Qs | "T_{dim}" (×11) |

### Dimensions (11)

`REGION`, `SEGMENT`, `PRODUCT_SOLUTION`, `PRODUCT_GROUP`, `LINE_OF_BUSINESS`, `DO_FIT`, `SOLUTION_TYPE`, `PRIMARY_CHURN_TYPE`, `CHURN_CATEGORY`, `CHURN_LABEL`, `ARR_BAND`

### Export

- `export_excel(df)` → `reporting/01_csm_sfdc_{quarter}_{timestamp}.xlsx`
- Sheets: Base Data, CSM Totals, CSM Quarterly Trend, 11 quarterly dimension sheets (`Q_REGION`, etc.), 11 trend dimension sheets (`T_REGION`, etc.) = **25 sheets**

### `main()`

Console output: row counts, CSM totals scorecard (one line per CSM), then Excel export.
