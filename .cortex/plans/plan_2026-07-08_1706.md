## Plan: New EO Deep Dive from SF Opportunity Product Table

### Context
The current `09_eo_deep_dive.sql` uses `EXEC_DECK_RENEWAL_RATES_PRODUCT_GROUP` (7 queries, renewal-rate focused). The user wants a **new version** using `RAW_OPPORTUNITY_LINE_ITEM_REPORT` (SF Opportunity Product) with churn-specific breakdowns matching the DAX logic in the attached file.

Key DAX translations:
- **AP_SPREAD_PCT**: Line item's `ANNUAL_PRICE_C` / SUM of all line items on same opportunity
- **DOWNGRADE_AMOUNT_SPREAD**: `ap_spread_pct * opp.CHURN_AMOUNT_EXPECTED_C` (for downgrades)
- **TOTAL_CHURN**: Full churn = `ANNUAL_PRICE_C / fx_rate` (Closed Lost); Downgrade = spread amount
- **CHURN_LABEL**: IF downgrade_spread > 0 THEN 'Downgrade' ELSE 'Full Churn'
- **CHURN_CATEGORY_CALCULATED**: SWITCH on `TYPE_OF_CHURN_C` → Fit Failure, Adoption Failure, Product, Commercial, External, Lack of Data, Uncategorized
- **EXP_LABEL**: IF avg experiments/month < 5 THEN 'Low Tester' ELSE 'High Tester'
- **FIT**: From `ACCOUNT.DOFIT_C` (Good Fit / Bad Fit)
- **SEGMENT**: From `ACCOUNT.SEGMENT_C` (Enterprise / Mid-Market)
- **REGION-SEGMENT**: Concatenation of `REGION` + `SEGMENT`

### Implementation Steps

**Step 1: Rewrite `queries/09_eo_deep_dive.sql`** — 6 queries:

1. **Downgrade vs Full Churn by Product Group** (within EO products)
2. **Total Churn by Good Fit / Bad Fit**
3. **Total Churn, Downgrades, Full Churn by Churn Category + %**
4. **Total Churn, Downgrades, Full Churn by Experimentation Label + %**
5. **Same by Region-Segment**
6. **Detailed account list**: account name, region-segment, fit, exp label, downgrade ARR, churn ARR, total churn ARR, % of total

All queries share a common base CTE:
- Source: `RAW_OPPORTUNITY_LINE_ITEM_REPORT` → `RAW_OPPORTUNITY_REPORT` → `SKU` → `ACCOUNT` → `OPPORTUNITY_OWNERS` → `EXP_ADOPTION` → `CURRENCY`
- Filter: `PRODUCT_SOLUTION = 'Experience Optimization'`, Stage = Closed Lost or Downgrade, standard CS pipeline exclusion, quarter = `:target_quarter`
- Calculated fields per DAX: `ap_spread_pct`, `downgrade_spread`, `full_churn_arr`, `total_churn`, `churn_label`, `churn_category_calculated`, `exp_label`, `fit`, `region_segment`
