## Context

The report has 5 scorecard rows (Total, Excl EOL, Excl Delinquent, Full Churn, Downgrades), ~30+ chart calls across sections 2-7, and ~12 trend charts. The data has `ARR_RENEWAL` for the renewal base. `scorecards_split()` in the analysis file computes KPIs but doesn't include renewal base or RR.

## Implementation Steps

### 1. `08b_digital_cs_churn_analysis.py` — Add RR + renewal base to `scorecards_split()`

Add to the returned dict:
- `renewal_accts`: count of all accounts in target quarter (not just churn)
- `renewal_arr_k`: total ARR_RENEWAL in $k
- `rr_total`: RR% = (renewal - total_churn) / renewal * 100
- `rr_ex_eol`: RR% excluding EOL products
- `rr_ex_delinq`: RR% excluding delinquent
- `rr_fc`: RR% for full churn only
- `rr_dg`: RR% for downgrades only

### 2. `08b_digital_cs_churn_html.py` — Add renewal base scorecard as first card

Insert a new first scorecard card in the "TOTAL CHURN" row:
```html
<div class="scorecard"><div class="label">RENEWAL BASE</div><div class="value sm" id="sc-renewal"></div></div>
```
Populate via JS: `KPIs.renewal_accts + ' accts / $' + (KPIs.renewal_arr_k/1000).toFixed(1) + 'M'`

### 3. `08b_digital_cs_churn_html.py` — Add RR to each scorecard row

Add an RR card to each scorecard row:
- Total row: `rr_total`
- Excl EOL row: `rr_ex_eol`  
- Excl Delinquent row: `rr_ex_delinq` (combine into same row)
- Full Churn row: `rr_fc`
- Downgrade row: `rr_dg`

### 4. `08b_digital_cs_churn_html.py` — Update all chart titles

Apply pattern `"Digital - <Metric> by <Dimension> - {TARGET_QUARTER}"` to all ~30 stacked bar calls and ~12 trend chart titles. Examples:
- `'Churn by Region'` → `'Digital - Churn by Region - {TARGET_QUARTER}'`
- `'Total Digital Churn ARR by Quarter'` → `'Digital - Total Churn ARR - 8Q Trend'`
- `'EO Churn ARR by Segment'` → `'Digital - EO Churn by Segment - 8Q Trend'`
- Regional: `key + ': By Category'` → `'Digital - ' + key + ' Churn by Category - {TARGET_QUARTER}'`

### 5. Run and verify

## Verification

Run `python3 pandas/08b_digital_cs_churn_html.py` and open the HTML to confirm scorecards show RR and renewal base, and chart titles follow the new pattern.
