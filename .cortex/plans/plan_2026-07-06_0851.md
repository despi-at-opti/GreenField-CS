### Key Technical Decisions

- **Native PPTX charts**: Using `pptx.chart.data.CategoryChartData` + `XL_CHART_TYPE.LINE_MARKERS` / `XL_CHART_TYPE.COLUMN_CLUSTERED` for editable charts
- **Data points visible**: Set `marker.style` and `marker.size` on each series; data labels enabled
- **Comments box**: 0.4" tall text box at bottom of every content slide with "Commentary:" placeholder and border
- **Brand**: Optimizely Blue (#0037FF) title bars, white backgrounds, chart palette from `CHART_PALETTE_HEX`
- **Font minimum**: Pt(11) for all body text, Pt(9) for table cells
- **Output filename**: `2026_Q2_Analyses_ONB_AgeCohort_{timestamp}.pptx`
