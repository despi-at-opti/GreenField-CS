## Context

The scorecard_dimensions section already has "By SFDC Segment" (Section 4) showing Renewal ARR/Churn and Renewal Rate as two bar charts. After this section, the user wants two additional horizontal bar charts showing the **Region × SFDC Segment** cross-tab (similar to how "Product Solution by Region" works in Section 9).

The existing pattern for cross-tabs: SQL produces `dimension_type = "X by Y"` with `dimension_value = "X - Y"` format, and the renderer groups by the first part with separators.

## Implementation Steps

### Step 1: Add Section 10 to `02_scorecard_dimensions.sql`

Add a `UNION ALL` before the final `ORDER BY`, creating a new section:
```sql
-- SECTION 10: By SFDC_SEGMENT × REGION
SELECT
    'SFDC Segment by Region' AS dimension_type,
    COALESCE(SFDC_SEGMENT, 'Unknown') || ' - ' || COALESCE(REGION, 'Unknown') AS dimension_value,
    COUNT(DISTINCT CASE WHEN ARR_RENEWAL > 0 THEN MASTER_CUSTOMER_ID END) AS renewal_count,
    ROUND(SUM(ARR_RENEWAL), 2) AS renewal_arr,
    COUNT(DISTINCT CASE WHEN ARR_CHURN < 0 THEN MASTER_CUSTOMER_ID END) AS churn_count,
    ROUND(SUM(ARR_CHURN), 2) AS churn_arr,
    ROUND((SUM(ARR_RENEWAL) + SUM(ARR_CHURN)) / NULLIF(SUM(ARR_RENEWAL), 0), 4) AS renewal_rate
FROM customer_base
GROUP BY SFDC_SEGMENT, REGION
```

### Step 2: Add rendering in `render_html.py`

After line 1074 (end of SFDC Segment section), add rendering for the cross-tab using horizontal bar charts — same pattern as "Product Solution by Region" (lines 1093-1144):
- Filter `main_df` where `DIMENSION_TYPE == "SFDC Segment by Region"`
- Group labels by SFDC Segment (Enterprise, Mid-Market) with separator rows
- Render two horizontal bar charts side by side: ARR & Churn | Renewal Rate
