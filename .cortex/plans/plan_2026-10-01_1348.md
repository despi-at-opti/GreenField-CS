## Context

Rewriting the 03_sst report to focus on WebEx-only metrics over 5 years, presented per year. Current SQL is cross-sectional (one row per MCID, one year). Need to change to one row per MCID per year, 5 years back, Web Experimentation only.

## Implementation Steps

### Step 1: Rewrite SQL (`03_sst_by_csm_exp_v_retention.sql`)

- **Generate 5 yearly cohorts** using a `year_range` CTE: `[current_year-4 .. current_year]`
- **Grain**: one row per MCID per COHORT_YEAR
- **Product filter**: Web Experimentation only (drop Feature Experimentation everywhere)
- **ARR**: year-start snapshot per cohort year from `ARR_REPORT`
- **Experiment activity**: L12M rolling from each year-end (Dec 31) — same as current logic but repeated per year. Counts: exps_started, by type (ab_test, mab, stats_accel, multivariate, p13n, targeted_delivery), by classification, stat_sig, distinct_creators, active_months
- **Retention**: current logic per year (Full Churn / Downgrade / Retained based on EXP churn movements in that year + ARR presence check)
- **Churn**: EXP churn scoped to each year
- **Cost per experiment**: ARR / exps_started per year
- **Remove**: feature_flags CTE (FX only), total_churn CTE (all products), dark_flag logic (simplify: dark = 0 exps)
- **Keep**: ARR bands, account dimensions (CSM_MANAGER_NAME, REGION, etc.)
- **Output columns**: `COHORT_YEAR, MASTER_CUSTOMER_ID, CUSTOMER_NAME, CSM_MANAGER_NAME, ARR, ARR_BAND, RETENTION_STATUS, RENEWAL_ARR, EXP_TOTAL_CHURN_ARR, EXP_FULL_CHURN_ARR, EXP_DOWNGRADE_ARR, EXPS_STARTED_L12M, EXPS_AB_TEST, EXPS_MAB, EXPS_STATS_ACCEL, EXPS_MULTIVARIATE, EXPS_P13N, EXPS_TARGETED_DELIVERY, CLASS_AB_TEST, CLASS_HOTFIX, CLASS_AA_TEST, CLASS_IMPLEMENTED, CLASS_P13N, CLASS_MEASUREMENT, CLASS_FEATURE_ROLLOUTS, EXPS_STAT_SIG, ACTIVE_MONTHS, EXPS_PER_MONTH, DISTINCT_CREATORS, COST_PER_EXPERIMENT, STAT_SIG_RATE, DARK_FLAG`

### Step 2: Rewrite analysis.py

- **`load_data()`**: reads new SQL, returns multi-year DataFrame with `COHORT_YEAR` column
- **Remove**: all current aggregate functions (headline_kpis, utilisation_breakdown, arr_band_breakdown, dark_*, cost_*, product_mix, breadth, creators, stat_sig_by_tier, experiment_type/class breakdowns, correlation_*, scatter, retention_by_*, heatmap_*)
- **Keep**: `assign_utilisation_tier()` (applied per year), `TIER_ORDER`, `BAND_ORDER`, `STAT_SIG_ORDER`, `CSM_MANAGERS`, `_STD_AGG` pattern

- **Add `yearly_metric_stats_by_tier(df, metric_col, tier_col)`**: same but grouped by `[COHORT_YEAR, tier_col]`

- **Add `yearly_rr(df)`**: RR per year = `max(0, (sum(RENEWAL_ARR) + sum(EXP_TOTAL_CHURN_ARR)) / sum(RENEWAL_ARR))` grouped by COHORT_YEAR
