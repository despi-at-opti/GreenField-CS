## Context

`CUSTOMER_AGE_MONTHS_AT_TIME_OF_RENEWAL` exists in both Customer table (account-level) and Product Group table (product-level). Data confirmed: 4 cohorts work well globally (21/55/61/817 accounts) and by product family (EO/EC/CMS/Opal).

## Implementation Steps

### Step 1: Create `11_cohort_analysis.sql`

Two queries:
- **Query 1 (Global)**: From `EXEC_DECK_RENEWAL_RATES_CUSTOMER` — cohort by age bucket, accounts, renewal ARR, churn ARR, renewal rate
- **Query 2 (By Product Family)**: From `EXEC_DECK_RENEWAL_RATES_PRODUCT_GROUP` (deduped) — cohort × product family (EO/EC/CMS/Opal), same metrics

### Step 2: Add to `query_tools.py`

New function `cohort_analysis(connector, target_quarter)` → returns `{"global": df, "by_product": df}` using `_run_multi_query_file`.

### Step 3: Register in `main.py`, `brand_config.py`, `render_html.py`

Add `cohort_analysis` to `TOOL_REGISTRY`, `ANALYSIS_ORDER`, `ANALYSIS_TITLES`, `_SECTION_BUILDER`.

### Step 4: Create `_section_cohort_analysis()` in `render_html.py`

Chart.js:
1. **Bar chart**: Global cohort renewal rate (4 bars: 0-12, 12-24, 24-36, 36+)
2. **Summary table**: Global cohort with accounts, renewal ARR, churn ARR, RR
3. **Grouped bar chart**: Cohort × Product Family (EO/EC/CMS/Opal) renewal rates
4. **Detail table**: Product family breakdown by cohort

### Step 5: Test

```bash
python3 main.py --quarter 2026-Q2 -f html -a cohort_analysis
```
